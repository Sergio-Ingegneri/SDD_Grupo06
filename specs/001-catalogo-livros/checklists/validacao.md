# Checklist de validação — Catálogo de Livros

Marque os itens após executar com `npm run api` e `npm run dev` em terminais separados.

- [ ] Com a API ativa, os livros iniciais aparecem ao abrir a página.
- [ ] Com `livros: []` no `db.json`, aparece `Nenhum livro cadastrado`.
- [ ] Um livro válido aparece após o cadastro e continua após recarregar.
- [ ] Título vazio, autor vazio e valores só com espaços não realizam POST.
- [ ] Com a API parada, a consulta mostra erro e `Tentar novamente`.
- [ ] Após religar a API, `Tentar novamente` recupera a lista.
- [ ] Com a API parada durante o cadastro, a mensagem aparece e título/autor são preservados.
- [ ] Após religar a API, o cadastro pode ser reenviado.
